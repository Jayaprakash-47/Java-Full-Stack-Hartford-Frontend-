# CSS Project

A comprehensive collection of CSS layout and styling examples demonstrating modern web design techniques.

## 📁 Project Structure

```
CSS/
├── grid.html                # CSS Grid layout example
├── grid.css                 # Grid styles
├── responsive_flexbox.html  # Flexbox responsive layout
├── responsive_flexbox.css   # Flexbox styles
├── product.html             # Product showcase page
├── product.css              # Product page styles
├── images/                  # Image assets
│   └── h.avif              # Sample image
└── README.md               # This file
```

## 📄 Files Overview

### Grid Layout (`grid.html` & `grid.css`)
Modern CSS Grid implementation showcasing:
- Grid container setup
- Grid item placement
- Responsive grid layouts
- Gap and alignment properties
- Grid templates

**Key Features:**
- Multi-column layouts
- Auto-fit and auto-fill properties
- Responsive breakpoints

### Responsive Flexbox (`responsive_flexbox.html` & `responsive_flexbox.css`)
Flexible box model demonstration including:
- Flex container and item properties
- Direction and wrapping
- Alignment and justification
- Responsive mobile-first design
- Cross-browser compatibility

**Key Features:**
- Mobile-first approach
- Flexible scaling
- Media queries for different screen sizes

### Product Showcase (`product.html` & `product.css`)
Product display page featuring:
- Product grid layout
- Card-based design
- Hover effects and transitions
- Typography and spacing
- Image optimization with AVIF format

**Key Features:**
- Modern card design
- Interactive hover states
- Responsive product grid
- Professional styling

## 🎯 Purpose

This folder demonstrates:
- **Layout Techniques:** CSS Grid vs Flexbox
- **Responsive Design:** Mobile-first development
- **Modern CSS:** Variables, gradients, transitions
- **Best Practices:** Clean, maintainable code

## 🚀 Getting Started

1. **Open files directly:**
   - Double-click any `.html` file to view in browser

2. **Using a local server** (recommended):
   ```bash
   cd CSS
   python -m http.server 8000
   ```
   Navigate to:
   - Grid: `http://localhost:8000/grid.html`
   - Flexbox: `http://localhost:8000/responsive_flexbox.html`
   - Product: `http://localhost:8000/product.html`

# Green Valley Farmhouse - Website

A modern, responsive website for a farmhouse vacation rental property showcasing accommodations, amenities, gallery, and booking features.

## 📁 Project Structure

```
Farmhouse/
├── index.html          # Homepage with hero section & features
├── gallery.html        # Photo gallery
├── amenities.html      # Facilities & amenities list
├── booking.html        # Reservation booking form
├── contact.html        # Contact information & inquiry form
├── rules.html          # House rules & policies
├── style.css           # Main stylesheet
├── images/
│   └── h.avif         # Farmhouse images
└── README.md          # This file
```

## 🚀 Getting Started

### View Locally
1. **Direct browser open:**
   - Navigate to the folder
   - Double-click `index.html`

2. **Using a local server** (recommended):
   ```bash
   cd Farmhouse
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser

### Navigation
Use the header navigation to move between pages:
- **Home** - Main landing page
- **Gallery** - Photo showcase
- **Amenities** - Facilities list

## 🎯 Customization

To customize for your property:

1. **Update content:** Edit text in HTML files
2. **Change colors:** Modify hex values in `style.css`
3. **Add images:** Replace `images/h.avif` with your photos
4. **Update contact info:** Change phone and location in footer
5. **Modify amenities:** Edit `amenities.html`

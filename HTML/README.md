# HTML Project

A collection of HTML practice files demonstrating fundamental web forms and semantic markup.

## 📁 Project Structure

```
HTML/
├── demo.html       # Semantic HTML structure demo
├── form.html       # Interactive form examples
└── README.md       # This file
```

## 📄 Files Overview

### `demo.html`
A demonstration file showcasing fundamental HTML elements and semantic structure including:
- Page layout and headings
- Paragraphs and text formatting
- Semantic HTML5 elements
- Basic document structure

### `form.html`
Interactive form examples covering:
- Text input fields
- Checkboxes and radio buttons
- Text areas
- Form submission
- Input validation basics

## 🎯 Purpose

This folder serves as a beginner-friendly introduction to HTML, perfect for learning:
- HTML syntax and element usage
- Form creation and handling
- Semantic markup best practices
- Accessibility fundamentals

## 🚀 Getting Started

1. Open any `.html` file in your web browser
2. Right-click and select **"Open with"** → Choose your preferred browser
3. Or use a local server for testing forms:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`

## 💡 Use Cases

- Learning HTML fundamentals
- Understanding form structure
- Reference for common HTML patterns
- Base templates for web projects

## 📝 Notes

- Files are standalone and can be opened directly in any browser
- No external dependencies required
- Forms demonstrate HTML5 input types and validation
